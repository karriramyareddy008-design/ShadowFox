# Cricket Fielding Performance Analysis

## Players Selected
- Virat Kohli
- Hardik Pandya
- Mohammed Siraj

## Objective
To analyze fielding performance using a custom scoring model.

## Scoring Criteria
- Catch = 10 points
- Run Out = 15 points
- Direct Hit = 20 points
- Missed Catch = -5 points
- Fielding Error = -3 points

## Methodology
Data was recorded ball-by-ball and performance score was calculated using Excel formulas.

## Conclusion
The player with the highest total score demonstrated superior fielding performance based on the scoring model.
